# 🤖 WebSogood — Discord AI Bot หลายเซิร์ฟเวอร์

บอท Discord ที่แชทด้วย AI ได้ (พร้อมระบบสำรองหลายค่ายอัตโนมัติ) มีระบบดูแลเซิร์ฟเวอร์ครบชุด
และมีฟีเจอร์ที่คิดขึ้นเองไม่เหมือนใคร อย่างระบบ "ความฝันของบอท" และเกมล่าของวิเศษที่ต่อยอดจากมัน

## 🔧 การติดตั้ง

```bash
npm install
```

1. คัดลอกไฟล์ `.env` (มีคำอธิบายกำกับทุกบรรทัดอยู่แล้ว) แล้วใส่ค่าจริงของคุณ:

   | ตัวแปร | คำอธิบาย |
   |---|---|
   | `DISCORD_TOKEN` | Token ของบอท จาก [Discord Developer Portal](https://discord.com/developers/applications) → Bot → Reset Token |
   | `OWNER_ID` | Discord User ID ของเจ้าของบอท (เปิด Developer Mode → คลิกขวาโปรไฟล์ตัวเอง → Copy User ID) ใส่ได้หลายคนคั่นด้วย `,` หรือใส่ `ALL` เพื่อให้ทุกคนใช้แผงควบคุมได้ |
   | `PANEL_CMD` | คำสั่งพิมพ์เพื่อเปิดแผงควบคุม (ค่าเริ่มต้น `!panel`) |
   | `PORT` | พอร์ตของ Web Server (บน Render จะกำหนดให้อัตโนมัติ ไม่ต้องแก้) |
   | `MONGODB_URI` | Connection string ของ MongoDB (เช่นจาก [MongoDB Atlas](https://www.mongodb.com/atlas)) |

2. รันบอท:

   ```bash
   npm start          # รันปกติ
   npm run dev        # รันแบบ auto-restart เมื่อแก้โค้ด (node --watch)
   ```

### Deploy บน Render

ใส่ค่าตัวแปรด้านบนใน **Environment** ของ Web Service แทนการสร้างไฟล์ `.env` โดยตรง — โปรเจกต์มี Web Serverในตัว (Express) สำหรับกัน Render พักเครื่อง (sleep) อยู่แล้ว

## 📋 คำสั่งทั้งหมด

บอทลงทะเบียนคำสั่งอัตโนมัติทุกเซิร์ฟเวอร์ที่เชิญเข้าไป ไม่ต้องรันสคริปต์ deploy เอง

### พิมพ์ด้วย `!` (Prefix Commands)
| คำสั่ง | คำอธิบาย |
|---|---|
| `!panel` (หรือค่าที่ตั้งใน `PANEL_CMD`) | เปิดแผงควบคุมบอทเต็มรูปแบบ (เฉพาะเจ้าของบอท/แอดมิน) |
| `!help` | วิธีใช้งานบอท |
| `!ping` | เช็คว่าบอทออนไลน์อยู่ |
| `!stats` | สถิติการใช้งานแบบเรียลไทม์ |
| `!rank` | เลเวล/XP ของตัวเอง |
| `!leaderboard` | อันดับ XP สูงสุดในเซิร์ฟเวอร์ |
| `!imagine <คำบรรยาย>` | สร้างภาพด้วย AI |
| `!avatar` | สุ่มเปลี่ยนรูปโปรไฟล์บอท (แอดมิน) |
| `!reset` หรือ `!ลืม` | ล้างความจำบทสนทนาของคุณกับ AI |

## 🛠️ หมายเหตุ: แก้ปัญหาคำสั่งซ้ำ/คำสั่งผีค้างเมนู

เดิมโปรเจกต์นี้ลงทะเบียนคำสั่งทั้งแบบ **Global** (`client.application.commands.set(...)`) และแบบ **เฉพาะเซิร์ฟเวอร์** (`guild.commands.set(...)`) พร้อมกัน
ถ้าการอัปเดต Global ล้มเหลว (เช่นตอนคำสั่งมีจำนวนมากขึ้นเรื่อยๆ) รายการ Global เก่าจะค้างอยู่และไปซ้อนกับคำสั่งเฉพาะเซิร์ฟเวอร์
ทำให้เห็นคำสั่งซ้ำหรือคำสั่งเก่าที่ไม่มีในโค้ดแล้ว (ผี) โผล่มาในเมนูพิมพ์คำสั่ง

ตอนนี้แก้แล้วโดย **ลบการลงทะเบียนแบบ Global ออกทั้งหมด** (ไม่จำเป็นอยู่แล้ว เพราะคำสั่งเฉพาะเซิร์ฟเวอร์ครอบคลุมทั้งเซิร์ฟเวอร์เดิมและเซิร์ฟเวอร์ใหม่อยู่แล้ว)
และเพิ่มการล้าง Global Commands เก่าทิ้งครั้งเดียวตอนบอทสตาร์ท (`client.application.commands.set([])`) — รันบอทเวอร์ชันนี้ครั้งแรกแล้วรอสักครู่ คำสั่งซ้ำ/คำสั่งผีจะหายไปเอง

## 🐛 หมายเหตุ: แก้บั๊ก Giveaway/Prophecy ไม่หมดเวลาอัตโนมัติ

ระหว่างตรวจสอบโค้ดทั้งหมดพบว่า `giveawayCache` และ `propheciesCache` (ตัวแปรภายในของ `lib/storage.js` ที่ใช้เช็คว่ากิจกรรม/คำทำนายไหนครบเวลาแล้วบ้าง) **ไม่เคยถูก export ออกมาให้ `index.js` ใช้งานเลย** ตั้งแต่ต้น
ทำให้ตัวจับเวลาที่เช็คทุก 20-30 วินาที error เงียบๆ ทุกรอบ (ถูกดักไว้โดย `process.on('uncaughtException', ...)` เลยไม่ทำให้บอทล่ม แต่ก็แปลว่า **Giveaway ไม่เคยจบอัตโนมัติ และคำทำนายไม่เคยเปิดผนึกเองเลย** ต้องรอให้แอดมินสั่ง `/giveaway end` เอาเองตลอดมา)

แก้แล้วโดยเพิ่ม `giveawayCache` และ `propheciesCache` เข้าไปใน `module.exports` ของ `lib/storage.js` — ตอนนี้ทั้งสองระบบจะจบ/เปิดผนึกอัตโนมัติตามเวลาที่ตั้งไว้แล้ว

## 🗄️ โครงสร้างโปรเจกต์

```
index.js          # เชื่อมต่อ Discord จริง (Client, Event handlers, Slash/Context Menu Commands)
lib/
  storage.js       # โมเดลข้อมูล MongoDB ทั้งหมด + ฟังก์ชันอ่าน-เขียน
  ai.js            # เรียก AI หลายค่ายพร้อมระบบสำรองอัตโนมัติ
  panels.js        # UI แผงควบคุม (Embed/Button/Select Menu)
test/run-all.js   # เทสพื้นฐาน
```

ข้อมูลทั้งหมดเก็บใน MongoDB (Mongoose) — ตั้งค่าเซิร์ฟเวอร์แยกกันเป็นรายกิลด์ ปรับผ่านแผงควบคุมหรือ Slash Command ได้ทั้งหมด ไม่ต้องแก้โค้ด
